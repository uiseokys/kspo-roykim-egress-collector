# 조용필 공연일 올림픽공원 도시데이터 전체 수집

조용필 & 위대한 탄생 콘서트(KSPO DOME, 2026-11-27~29) 동안 서울시 실시간 도시데이터의 **전체 항목**을 모읍니다. 로이킴 때의 `collector.py`는 인구만 받았습니다.

| 날짜 | 공연 시작 | 구간 A (KST) | 구간 B (KST) |
|---|---|---|---|
| 11/27 | 19:00 | 18:00–22:30 | 21:30–다음 날 01:00 |
| 11/28 | 18:00 | 17:00–21:30 | 20:30–다음 날 00:00 |
| 11/29 | 17:00 | 16:00–20:30 | 19:30–23:00 |

공연 시작 1시간 전부터 6시간 뒤까지 2분 간격으로 조회합니다.

## 남기는 항목

| 항목 | 요약 CSV의 열 |
|---|---|
| 인구·연령대·성별 비율 | `ppltn_time`, `ppltn_min`, `ppltn_max`, `rate_0`…`rate_70`, `male_rate`, `female_rate` |
| 지하철·버스 실시간 승하차 | `sub_on_5_min`처럼 `sub`/`bus` × `on`/`off` × 최근 `5`·`10`·`30`분·그날 누적(`acml`) × `min`/`max` |
| 주차장 | 실시간 연동된 주차장 수 `prk_lots`, 주차면 합 `prk_capacity`, 현재 주차 대수 합 `prk_current` |
| 그 밖 | 따릉이 거치 대수, 도로 평균 속도, 기온·강수 형태, 상권 결제 건수 |

올림픽공원에서 실제로 채워지는 것(2026-11-26 14시 시험 실행 기준):

- 채워짐: 인구·연령대·성별 비율, 버스 승하차(정류장 17곳 합), 따릉이 대여소 12곳의 거치 대수, 도로 평균 속도, 날씨
- 비어 있음: 지하철 실시간 승하차(주변 역 4곳은 목록에 있으나 값이 없음), 주차장 현재 대수(4곳 모두 실시간 연동 안 됨), 상권 결제
- 비어 있던 항목도 값이 들어오면 그대로 기록됩니다.

- `citydata/data/<공연>/<구간>-<실행>.csv`: 조회마다 한 줄 요약
- `citydata/data/<공연>/<구간>-<실행>.jsonl`: 추린 원본(주차장별·따릉이 대여소별 값 포함)
- 전체 응답 원본은 한 번에 15만 글자쯤이라 저장소에 넣지 않고 Actions 아티팩트(`citydata-…`, 90일)로만 보관합니다.

## 자동 실행

`.github/workflows/collect-citydata.yml`이 공연 기간 내내 30분마다 예약되어 있습니다. 실행된 시각이 수집 구간 안(구간 시작 45분 전부터)이면 그 구간을 끝까지 수집하고, 아니면 몇 초 만에 끝납니다. 같은 구간은 한 번에 하나만 수집하며, 뒤에 온 실행은 기다렸다가 앞 실행이 끝나면 이어받습니다.

이렇게 한 이유: 로이킴 때 이 저장소의 예약 실행은 예정보다 7~8시간 늦게 돌아 모두 구간을 놓쳤고, 실제 수집은 수동 실행으로 했습니다. 30분마다 예약해 두면 얼마나 늦든 구간 안에 도는 실행이 생깁니다.

**그래도 예약이 돌지 않으면** 공연 시작 1시간 전쯤 직접 실행합니다: Actions → "조용필 공연일 도시데이터 전체 수집" → Run workflow → `auto`. 구간 A가 끝나기 전(시작 2시간 뒤쯤) 한 번 더 `auto`를 실행하면 구간 B가 이어집니다.

```bash
gh workflow run collect-citydata.yml -R uiseokys/kspo-roykim-egress-collector -f action=auto
```

## 시험

- Run workflow → `check`: 올림픽공원을 한 번 조회해 항목이 채워지는지 로그로 확인
- Run workflow → `test`: 5분 수집해 저장소에 올라가는지 확인(`citydata/data/<날짜>_test/`)
- `python3 -m unittest citydata/test_collect_citydata.py`

인증키는 로이킴 수집기와 같은 저장소 Secret `SEOUL_POPULATION_API_KEY`를 씁니다. 파일과 로그에 넣지 않습니다.
