# 로이킴 공연일 올림픽공원 인구 수집

GitHub-hosted Linux에서 서울시 올림픽공원 인구 추정치를 5분마다 저장합니다. 뒷 구간 수집이 끝나면 회차별 그래프와 시간대별 CSV를 갱신합니다.

## 키 설정과 시험

1. 서울 열린데이터광장의 [서울시 실시간 인구데이터](https://data.seoul.go.kr/dataList/OA-21778/A/1/datasetView.do) 인증키를 발급받습니다.
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 이름을 `SEOUL_POPULATION_API_KEY`로 등록합니다. 키는 파일과 로그에 넣지 않습니다. 서울시 공식 API 요청 경로는 HTTP를 사용합니다.
3. **Actions → 로이킴 공연일 인구 수집 → Run workflow**에서 `check`를 선택해 올림픽공원 응답을 확인합니다. `sample`은 서울시가 공개한 광화문·덕수궁 샘플로만 연결을 확인합니다.

| 회차 | 실제 수집 창(KST) |
|---|---|
| 2026-11-20 | 18:30–다음 날 02:00 |
| 2026-11-21 | 16:30–다음 날 00:00 |
| 2026-11-22 | 15:30–23:00 |

GitHub의 작업당 6시간 한도 때문에 회차를 앞·뒤 두 구간으로 나눕니다. 두 구간은 5분간 겹칩니다. GitHub가 예약 실행을 지연하면 남은 슬롯을 수집합니다. 올해 지정한 세 날짜를 넘기면 수집 호출을 종료합니다.

## 결과

Actions 실행 기록 하단의 Artifacts에서 `roykim-raw-…` 원본과 `roykim-report-…` 결과를 받습니다. 결과에는 PNG, CSV, 수집 범위표가 들어 있습니다. `report`로 결과를 다시 만들 수 있습니다. 저장된 관측 사이에 5분을 넘는 공백이 있으면 그래프의 선을 끊습니다. 인구는 공원 전체 추정치이며 공연의 실제 종료 시간은 별도 관측이 필요합니다.
